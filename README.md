# Elevator English

平日のエレベーター（1分 × 4回）で、語彙と表現を瞬間想起するPWA。1日15枚を固定し、英語を見て意味がすぐ浮かぶかだけを試す。通勤での新規インプットと、休日のディクテーションはここには入れない。
公開URL: https://hideyuki-mon.github.io/elevator-english/

## 構成

| ファイル | 役割 |
|---|---|
| `index.html` | **唯一のソース**。UI・スタイル・100フレーズ・ロジックすべてここ |
| `fonts/*.woff2` | 自己ホストのDM Sans（オフラインでも英文フォントが効く） |
| `build.js` | `sw.js` を生成（キャッシュ名は内容ハッシュから自動生成）＋健全性チェック |
| `sw.js` | 生成物。手で編集しない |
| `manifest.json` / `icon-*.png` | PWA設定・アイコン |

## 更新手順

1. `index.html` を編集（フレーズ追加・修正もここ）
2. `node build.js` （キャッシュ名が自動で変わる。チェックに失敗したら赤字で止まる）
3. `git add -A && git commit && git push` → GitHub Pagesが1〜2分で反映

## 学習ロジック（1分の瞬間想起）

- その日の15枚は、アプリを開いた時点で固定される。4回乗っても同じ15枚
- 入り方: 前日までの「もう一度」→ 期日が来た復習（最大5枚）→ 残りは未出の語彙・表現。Listening は後ろに回す
- 英語だけ出す。タップで日本語。**即答**なら間隔が伸び、**もう一度**なら次の1分の先頭に戻る
- 間隔: 1 → 3 → 7 → 16 → 35日（即答した回数で伸びる）
- 履歴は端末の `localStorage`（`ee_history` と `ee_day`）

## 操作

- カードをタップ＝意味を表示（Web Speech の発音は 🔊。オフライン可）
- **即答** / **もう一度**。意味が出たあと、右スワイプ＝即答、左スワイプ＝もう一度。キーボードは ← →
- 60秒で終了。乗り時間が長ければ「もう1分」（回数は増えない）
